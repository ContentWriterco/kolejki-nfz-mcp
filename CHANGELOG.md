# Changelog

- `find_care`: NFZ waiting lists near a place – forecast waiting time (NFZ API „Terminy leczenia” 1.4), people waiting, address, phone, distance, accessibility, children; stable or urgent, outpatient or hospital; everyday words mapped to NFZ benefit names.
- `find_benefits`, `data_sources`.
- CLI: `find`, `benefits`; Streamable HTTP with landing page, rate limit and anonymous stats.
